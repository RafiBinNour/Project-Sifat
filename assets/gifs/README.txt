Drop your own animated GIF mascots in this folder.

Then point the <img> tags in index.html at them, for example:

  <img class="mascot__image" src="assets/gifs/bear-ask.gif"
       width="260" height="260" alt="A shy little teddy bear holding a heart." />

The stylesheet already renders .mascot__image as a circle with a white ring
and a gentle floating animation, so a square GIF of 400 x 400 px or larger
looks best. Remember to update the alt text to describe the new image.

See section 8 of README.md for the full walkthrough.
